# Images Folder

Place the following images in this folder:

1. `carnation-border.png` - A decorative border of white carnations for the intro slide
2. `carnation-decoration.png` - White carnation decorations for the final slide
3. Your personal photos of you and Dharshana 

You can find free carnation images on sites like Unsplash, Pexels, or can create them using image generation tools.

For the best quality, use PNG images with transparent backgrounds for the decorative elements.
