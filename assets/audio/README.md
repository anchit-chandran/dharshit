# Audio Folder

Place the following audio files in this folder:

1. `thinking-out-loud.mp3` - Ed Sheeran's "Thinking Out Loud" for the intro and question slides
2. `youre-all-i-want.mp3` - Cigarettes After Sex's "You're All I Want" for the final slide

Note that you should ensure you have the right to use these songs for personal use. Alternatively, you can use royalty-free music that matches the mood of these songs.
