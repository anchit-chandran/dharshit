# Who Wants to be a Dharshillionaire?

A special interactive presentation to ask a special question.

## Project Overview
This is a personalized interactive presentation built with RevealJS to create a memorable moment.

## Development
1. Clone this repository
2. Open `index.html` in your browser to test locally
3. Add your personal photos to the `assets/images` directory
4. Customize the questions in `js/main.js` with your own memories

## Technologies
- RevealJS for presentation
- GSAP for animations
- GitHub Pages for hosting
